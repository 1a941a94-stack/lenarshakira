# CariGold portfolio — ready to deploy

Static portfolio built for `lenarshakira` with a dark cyber/technology visual identity matching the CariGold avatar and banner.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive visual design
- `script.js` — interactive demo switcher and copy-to-clipboard CTA
- `assets/avatar.png` — generated anonymous cyber avatar
- `assets/hero.png` — generated technology background

## Important positioning choice
The four interactive projects are explicitly labelled **DEMO CONCEPT**. They demonstrate product thinking and UI/architecture capability without claiming fake client work.

## Deploy to Vercel
The folder is deployable as a plain static site. No build command or framework is required.

If you later want a custom domain, point it at the deployed Vercel project after deployment.
